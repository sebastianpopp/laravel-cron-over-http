# Security Policy

## Supported Versions

Only the latest released version of this package is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather than opening a public issue.

Open a [GitHub security advisory](https://github.com/sebastianpopp/laravel-cron-over-http/security/advisories/new) with a description of the vulnerability and steps to reproduce it.

You should receive a response within a few days. Once the vulnerability is confirmed, a fix will be released as soon as possible and credit will be given to the reporter unless anonymity is requested.
